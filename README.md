# Palo

Palo is a collaboration platform designed to help small game development teams work together without needing to learn complex version-control workflows.

## Vision

Make game collaboration simple enough for beginners while providing the confidence of professional studio workflows.

## Initial Target

- Godot 3.x
- Windows
- Small indie teams and friends

## MVP

- Upload My Work
- Get Team Updates
- Automatic Backups
- Team Activity

Long-term, Palo aims to support multiple game engines through engine-specific plugins connected to a common collaboration platform.
