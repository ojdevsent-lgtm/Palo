# Palo Vision

## Mission

Palo helps beginner game developers collaborate with the confidence of a professional studio.

## Core Principles

1. Simplicity over complexity.
2. Hide Git terminology from users.
3. Protect users with automatic backups.
4. Make collaboration feel safe and approachable.

## Long-Term Vision

A unified collaboration platform supporting multiple game engines through dedicated plugins while sharing a common Palo ecosystem.
